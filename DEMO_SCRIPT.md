# Demo video script (2:45, screen recording + voice-over)

**Before recording:** set SERPAPI_KEY, pick ONE real business you have permission to show (or use the demo data and say so),
run it once so the cache is warm (recording then costs 0 searches), and zoom the browser to 125%.

| Time | Screen | Say |
|---|---|---|
| 0:00–0:15 | Google Maps on a phone: "dentist near me" in Mangalagiri, one clinic buried at #5 | "In Indian towns, this search decides who gets the patient. This clinic is #5 and has no idea why." |
| 0:15–0:30 | LocalLens home, type the business + city, press Analyze; the steps tick | "LocalLens is an agent built on SerpApi. It resolves the business, finds its real competitors around its location, checks three real searches, reads everyone's latest reviews and audits the website." |
| 0:30–1:00 | Score 36 vs competitor average 81, then the bars | "One number, fully explained: map visibility, reputation, profile, momentum, owner replies and website." |
| 1:00–1:25 | Competitor table | "These are the clinics Google actually ranks here. Same town, same service: they reply to reviews, have hours and photos, and link a website." |
| 1:25–1:55 | Fix list | "And it acts: a prioritised fix list, every item backed by evidence. Reply to the six unanswered negative reviews. Add opening hours: ten minutes." |
| 1:55–2:15 | WhatsApp summary: copy the Telugu | "Owners here live on WhatsApp, so the summary comes in English and Telugu, ready to send." |
| 2:15–2:35 | Scan-an-area tab: dental clinic, Mangalagiri | "For agencies, one search ranks every business in an area by fixable gap. That's a lead list." |
